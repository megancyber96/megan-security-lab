# 🔐 Megan Security Lab

Megan Security Lab is a beginner-friendly cybersecurity learning project built with HTML, CSS, and JavaScript.

The project provides interactive tools for learning fundamental security concepts directly in the browser.

## 🛡️ Features

- Password Strength Analyzer
- Secure Password Generator
- SHA-256 Hash Lab
- Salt Demonstration
- Cybersecurity Quiz

## 🔒 Privacy

The application runs locally in the browser.

It does not intentionally send passwords or practice data to a server, and no analytics or persistent application storage are used.

For safety, users should use made-up passwords when experimenting with the tools.

## 🎯 Purpose

This project was created as a hands-on way to learn cybersecurity concepts and web development.

## 💻 Technologies

- HTML
- CSS
- JavaScript
- Web Crypto API
